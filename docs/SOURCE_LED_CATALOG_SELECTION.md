# Επιλογή από πραγματικές προτάσεις, κάλυψη και ειδικά αιτήματα

Νεότερη κατεύθυνση χρήστη, 29/10/2026. Υπερισχύει της αρχικής μεθόδου επιλογής 500 από Overture confidence/website/grid quotas. Είναι ενημερωμένο specification· source acquisition και extraction tooling έχουν υλοποιηθεί τοπικά· revised curated shortlist, adaptive coverage engine και native free-text request flow παραμένουν εκκρεμή.

Περαιτέρω διευκρίνιση χρήστη: [VIDEO_SOURCE_RESEARCH.md](VIDEO_SOURCE_RESEARCH.md) υπερισχύει ως προς search strategy/venue counts. Broad orientation → έξυπνες query variants ανά input dimension → varied sources → permitted transcription/extraction → fact-checking → adaptive gap search. Τα παρακάτω αριθμητικά minima είναι optional quality benchmarks, όχι mandatory quotas. Local query planner/official YouTube connector/manual-link, audio download, and CPU ASR tooling exist. The first 20-video batch is raw, relevance-ranked without popularity statistics, and not approved for catalog use; transcription produced 19 evidence JSON files and one failure, with music-only/low-quality results recorded in the review audit. The newer default-creator batch supplements that historical pilot: eight verified channel-ID defaults, official statistics snapshots, multipart discovery, and local transcription. Structured extraction and name/alias Overture match proposals exist; paid execution, reviewed identity merges and the final curated release remain pending. See TRANSCRIPT_EXTRACTION.md.

## Ρόλος των δεδομένων

1. **Ευρύ basic inventory:** οι 41.461 Overture records βοηθούν exact identity matching, γεωγραφική και πρακτική αναζήτηση. Δεν θεωρούνται αυτομάτως συστάσεις ή πλήρης πόλη. Useful chains/fast food παραμένουν διαθέσιμα· χρειάζονται σωστή identity/category matching και trip-specific operational checks.
2. **Curated αρχική έκδοση ~500:** οι candidates προκύπτουν από πραγματικές προτάσεις σε άρθρα, city/museum/cultural guides, YouTube, TikTok, Instagram, Google Maps και ενδεχομένως Tripadvisor. Η Overture χρησιμοποιείται για αντιστοίχιση, όχι ως κλειστό σύνολο από το οποίο υποχρεωτικά επιλέγονται όλοι. Missing verified candidates μπορούν να προστεθούν. Luna μόνο για permitted extraction, συνδυασμό τεκμηρίων, annotations και κενά, όχι αυθαίρετη παραγωγή top lists από model memory.
3. **On-demand ειδικά αιτήματα:** search/retrieval στο broad inventory και published evidence πρώτα· νέα bounded έρευνα όπου λείπει το ζητούμενο και το επιτρέπει το budget. Exact selected pin/private save/add παραμένει χωριστή απλή flow χωρίς automatic paid research.

Οι 500 παραμένουν initial enriched target. Coverage minima και gaps καθορίζουν τη σύνθεση, όχι οι παλιές αυθαίρετες quotas 170/90/100/65/45/30. Αν δεν χωρά η χρήσιμη κάλυψη στις 500, παρουσιάζεται το συγκεκριμένο gap/κόστος πριν αλλαγή target· δεν εγκρίνεται σιωπηρά μεγαλύτερη paid παραγωγή.

## Πραγματικές πηγές προτάσεων

Συλλέγουμε source lists/videos/posts πριν δημιουργήσουμε την τελική shortlist. Κρατάμε title, creator/publisher, URL, publication/update date όπου υπάρχει, actual retrieval date, list scope (πόλη/περιοχή/category/style), exact recommended entity, reason/context και rank μόνο αν η πηγή το δίνει. YouTube references μπορούν να περιλαμβάνουν video timestamp και επιτρεπόμενο transcript excerpt· δεν υποσχόμαστε ότι κάθε social platform παρέχει bulk accessible content. Supported permitted metadata/content ή user-provided reference χρησιμοποιούνται όπου η αυτόματη πρόσβαση δεν διατίθεται. Actual adapter/terms/cost review προηγείται source acquisition.

Το “Top 100” μιας πηγής είναι recommendation claim του συγκεκριμένου publisher, όχι verified καθολικό ranking. Video views, TikTok virality, εμφάνιση σε Google Maps και star rating δεν μετατρέπονται σε ενιαίο quality score. Source independence ελέγχεται: copied lists και επαναδημοσιεύσεις δεν μετρούν ως ανεξάρτητες συστάσεις. Sponsorship/advertorial και παλιές προτάσεις επισημαίνονται όπου γνωστά. Προτιμάται corroboration από ανεξάρτητες πηγές για τη mainstream βάση, ενώ μια καλά τεκμηριωμένη niche/local πρόταση μπορεί να διατηρηθεί με σαφή recommendation evidence.

Mix: σημαντικά/core venues, σύγχρονα και δημοφιλή venues, εναλλακτικές/local discoveries, διαφορετικό ύφος και κόστος όπου τεκμηριώνεται. Popular δεν σημαίνει υποχρεωτικό ούτε αποκλείει practical/chain επιλογές για εξατομικευμένα αιτήματα. Ένα source brand ή creator δεν καθορίζει μόνος του όλες τις 500.

## Coverage minima

Απαίτηση χρήστη: ελάχιστες χρήσιμες επιλογές ανά κύρια κατηγορία και συνήθη υποκατηγορία. Τα ακόλουθα είναι **αρχικά proposed planning targets**, όχι συμφωνημένα τελικά πλήθη ή υπόσχεση διαθέσιμων venues:

| Coverage cell | Αρχικός στόχος |
|---|---|
| Σύγχρονα/δημοφιλή food venues | 20 distinct useful επιλογές με πραγματική recommendation evidence |
| Σύγχρονα/δημοφιλή bars/drinks venues | 20, χωριστά από food context |
| Popular/distinctive clubs | 20 εφόσον υπάρχουν κατάλληλες τεκμηριωμένες επιλογές· καταγράφεται έλλειμμα αντί padding |
| Κοινή υποκατηγορία, π.χ. specialty coffee, tapas, brunch, cocktail bars | Τουλάχιστον 5 identity-checked επιλογές, στόχος 8–10 όπου το επιτρέπουν sources/ποικιλία |
| Core sights / museums | Source checklist coverage και διαφορετικοί τύποι εμπειρίας· museums χωριστή coverage dimension από sights |
| Περιοχή × πρακτικό request | Bounded retrieval 3–5 κατάλληλων alternatives όπου υπάρχουν, χωρίς seed quota για κάθε πιθανό cell |
| Αυθαίρετο/niche type | Χωρίς εξαντλητικό pre-seed minimum· published evidence + on-demand search και explicit unknown/not_found |

Κάθε κύρια κατηγορία (food, coffee, bars, clubs, sights, museums, outdoors/day trips, shopping) αποκτά δικό της versioned coverage target στο city profile πριν το generation. Τα τελικά main-category minima θα οριστούν με βάση την πραγματική source supply και τη συνολική σύνθεση των ~500· τα top-20 cohorts δεν είναι το συνολικό πλήθος κάθε family. Subtypes είναι multi-label/contextual: ένα tapas venue μπορεί να καλύπτει food και drinks, με διαφορετική τεκμηρίωση. Μετράμε distinct entities ανά cell και distinct entities συνολικά, όχι διπλές εγγραφές.

Measured states: candidate count, identity-checked count, recommendation-backed count, enriched count, applicable factual completeness/freshness και gap προς target. Unknown style/price/accessibility δεν μετρά ως confirmed coverage. Κάθε cell έχει selection reasons και source references. Τα ελλείμματα δεν λύνονται με invented candidates ή model-assigned unsupported labels.

## Free-text type και retrieval

Standard category/pill επιλογές συνδυάζονται με “Πρόσθεσε τύπο / περιέγραψε τι ψάχνεις”. Αποθηκεύουμε original text και interpreted intent, χωρίς να απαιτείται ήδη registered subtype. Το original intent διατηρείται σε prompt και search· άγνωστο type δεν χάνεται σε enum mapping. Νέα concepts δεν γίνονται αυτόματα global hard filters ή public permanent categories.

Παραδείγματα:

- “Fast food κοντά στη στάση/περιοχή Χ”: broad inventory retrieval με κατάλληλες taxonomy/aliases, exact geography και route/time context. Αλυσίδες επιτρέπονται. Δεν περιορίζεται στις curated 500· current opening για το συγκεκριμένο trip ελέγχεται χωριστά.
- “Club με gothic style”: ελέγχουμε music/venue/event evidence και actual date όπου σχετίζεται. Gothic music night, gothic aesthetic και Gothic Quarter είναι διαφορετικές έννοιες· δεν χαρτογραφούνται σιωπηρά η μία στην άλλη. Αν το intent παραμένει αμφίσημο, ζητείται σύντομη διευκρίνιση. Δεν υποσχόμαστε ότι κάθε niche υπάρχει στην πόλη.

On-demand research χρησιμοποιεί catalog/evidence πρώτα, έπειτα επιτρεπόμενες συγκεκριμένες αναζητήσεις και Luna synthesis όταν χρειάζεται. AI memory δεν γίνεται venue fact source. New venue proposals χρειάζονται identity/provenance validation. Trip/user context παραμένει private· μόνο ανεξάρτητα τεκμηριωμένα permitted public facts μπορούν να προταθούν για admin-reviewed shared publication. Save/add δεν πυροδοτεί αυτόματα paid work.

## Fact-checking και επόμενο παραδοτέο

Recommendation sources απαντούν “γιατί αξίζει / τι ύφος έχει”. Πρακτικά facts ελέγχονται με authoritative venue/museum/operator sources: exact branch/address/coordinates, hours, prices, ticket/age/accessibility/dietary scope. `/5` ratings παραμένουν attributed platform snapshots με πραγματικό observed time, όχι συνδυασμένος popularity score. Description claims χρειάζονται evidence και estimates διακριτή σήμανση. Ισχύουν τα [field-level acceptance gates](CATALOG_ENRICHMENT_STAGE_3.md).

Επόμενο Stage-3 deliverable: source register και seed lists → exact matches/new candidate review → versioned category/subtype coverage matrix → source-backed revised ~500 manifest → representative 20-record Luna pilot μέσα στις 500, μετά το provider/cap gate. Δεν ξεκινά paid generation από τη σημερινή technical shortlist.
